3. Local Network Requirements & Limitations

DG Buzzer relies on peer-to-peer User Datagram Protocol (UDP) broadcasting within a shared Local Area Network (LAN):

  • Shared Wi-Fi or Hotspot: Both the host and player devices must be connected to the exact same Wi-Fi network or a personal mobile hotspot.
  • Network Isolation / AP Isolation: Certain corporate, university, or public guest Wi-Fi networks enable "Client Isolation" or "AP Isolation", which prohibits connected devices from communicating directly with each other. DarkGlance cannot guarantee App functionality on networks where peer-to-peer UDP traffic is blocked by network administrators or router settings.
  • Network Jitter & Timing: While DG Buzzer calculates buzzer timestamps with millisecond precision upon signal arrival, variations in local Wi-Fi signal strength, router latency, packet loss, or radio interference may influence delivery time. DG Buzzer is designed for friendly trivia, classroom quizzes, and social games.
