How it works

Connect all devices to the same Wi-Fi network and you're set.

1

Host creates a room

Choose Host, enter a room name and size, then press Start.

2

Players join

Choose Join, enter your name and tap the room from the list.

3

Start the round

When everyone's in, the host starts and all buzzers go active.

4

Buzz!

First to hit BUZZ wins. The host sees the full ranked timeline.
